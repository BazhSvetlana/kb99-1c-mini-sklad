# kb99-1c-mini-sklad
Мини-склад
Репозиторий содержит выгруженную в файловый формат конфигурацию 1С для лабораторной работы. В ней реализованы справочники, документы «ПриходнаяНакладная» и «ОказаниеУслуг», автоматический пересчёт суммы в табличных частях, базовые подсистемы и настройки видимости интерфейса.
## Что внутри

Структура папок соответствует стандартному формату файловой выгрузки конфигурации 1С:

- `Catalogs/` — справочники .
- `Documents/` — документы .
- - `Forms/` — формы объектов.
  -  `Subsystems/` — подсистемы.
- `Configuration.xml` — корневой файл описания конфигурации.

## Как открыть и собрать конфигурацию
Откройте базу в Конфигураторе.
В меню: **«Администрирование» → «Загрузить конфигурацию из файлов»**.
Укажите корневую папку репозитория (где находится `Configuration.xml`).
Подтвердите загрузку — платформа соберёт конфигурацию из файлов.
После загрузки выполните **«Обновить конфигурацию базы данных»** (F7).
Запустите в режиме «1С:Предприятие» для проверки объектов.
